# Tech Stack

- [Next.js](https://nextjs.org) — UI framework
- [Vercel](https://vercel.com) — Hosting and deployment
- [Tailwind CSS](https://tailwindcss.com) — Styling
- [Next Themes](https://github.com/pacocoursey/next-themes) — Color theme

Portfolio content (profile, experience, projects) lives under `app/data/` and is version-controlled—no headless CMS required.

## Run locally

```bash
git clone https://github.com/akash9676/Akash.graspins.com.git
cd Akash.graspins.com
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Refresh project screenshots

```bash
npm run screenshots
```

## Build

```bash
npm run build
```
